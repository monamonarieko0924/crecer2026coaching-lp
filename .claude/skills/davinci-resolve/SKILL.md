# DaVinci Resolve 操作・編集効率化ナレッジ

## 0. 回答するときのルール（最優先）

1. **バージョンを前提にする。** 2026-08 時点の最新は **DaVinci Resolve 21.0（2026年6月 正式リリース）／21.0.2（2026年7月）**。
   ユーザーのバージョンが不明で、答えがバージョンで変わる場合は「お使いのバージョンは？」と先に確認する。
2. **無料版 / Studio 版を区別する。** AI 系（Magic Mask、音声文字起こし、Voice Isolation、ノイズ除去、スーパースケール等）や一部コーデックは **Studio 限定**。
   「できません」と答える前に、Studio 限定機能かどうかを必ず切り分ける。
3. **ショートカットは「デフォルト値」であって絶対ではない。**
   Resolve はキーボードプリセット（DaVinci Resolve / Premiere Pro / Final Cut Pro 7 / Avid Media Composer など）を切り替えられ、ユーザーが独自に変更している可能性がある。
   確定させたいときは **`DaVinci Resolve` メニュー → `Keyboard Customization`（環境設定内のキーボードカスタマイズ）** で検索して確認するよう案内する。
   本ナレッジ内で `⚠️要確認` が付いた項目は、断定せずこの確認方法とセットで答える。
4. **一次情報を優先する。** 迷ったら Blackmagic Design 公式マニュアル（`DaVinci Resolve Reference Manual` PDF / `DaVinci Resolve 21 New Features Guide`）と公式フォーラムを根拠にする。
   ネットワーク制限で公式サイトに直接アクセスできない環境では、その旨を伝えたうえで「検証済み／未検証」を明示して答える。
5. **操作手順は "どのページで・どのメニューから・どのキー" の3点セット**で書く。ページが違うと同じ機能でも場所が違うため。
6. 推測で手順をでっち上げない。不明なら「公式マニュアルの該当章を確認してください」と言う方が価値が高い。

## 1. 効率化の考え方（これが本質）

編集速度は「機能を知っているか」より **手を動かす回数をどれだけ減らせたか** で決まる。優先順位は次のとおり。

1. **再生・停止・1フレーム移動をキーボードだけで完結させる**（J/K/L と ←/→）。ここが全作業時間の最大要因。
2. **マウスでクリップの端をドラッグしない。** トリムはキーボード（`,` `.` `Shift+,` `Shift+.`）とトリムモードで行う。
3. **同じ作業を2回やったらテンプレート化する。**（パワービン、Fusion/Text+ のプリセット、レンダープリセット、タイムラインテンプレート）
4. **素材探しの時間を消す。**（スマートビン、パワービン、メタデータ、ソーステープ、シンクビン）
5. **再生がカクついたら編集速度は必ず落ちる。** プロキシ／最適化メディア／レンダーキャッシュを先に整える。
6. **繰り返し作業は Cut ページに寄せる。** 尺の長いインタビュー・セミナー・トークもので特に効く。

## 3. 回答フォーマットの推奨

- 手順は番号付きで、**メニュー階層は `メニュー → サブメニュー → 項目` 表記**。
