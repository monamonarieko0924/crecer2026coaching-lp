## 21 の編集まわりの新機能（Cut / Edit ページ）

- **キーフレームの大幅強化**: 4点ベジェ制御、イージング、ループ、リバース、複数クリップ選択でのキーフレーム操作。
  エフェクト・テキスト・ジェネレーター・Fusion コンポジションを、編集ページから直接キーフレームできるようになった。
- **ピクチャーインピクチャー用の Resolve FX** が Cut / Edit ページに追加。
- **マルチカム改善**: 全アングルのオーディオトラックを保持できる／クリーンフィード・ビデオ出力へのアングルプレビュー／クリップ全体の尺を保持。
- **ソーステープがマルチカムクリップに対応**。マッチフレームがネストされたクリップ・マルチカムのソースメディアも辿れるようになった。
- **トランジションを選択するタイムラインメニュー項目**（Cut / Edit 両ページ）。
- **Lottie / OGraf グラフィックのサポート**、**Text+ のスペルチェック**、**スマートビンの新しい表示モード**。
- 新しい **Photo ページ**（写真の現像・編集）。
- カラーページはノードスタックが最大8レイヤーに、クリップグループと HDR スコープの改善。
- **Magic Mask の Render in Place**: 追跡対象の外部マットを生成し、元素材に自動でリンクする。

> 出典は Web 検索経由（CG Channel / PetaPixel / ProVideo Coalition / Newsshooter ほか）で確認。
> 詳細な仕様は公式 `DaVinci Resolve 21 New Features Guide`（PDF）で裏取りすること。

## 編集効率に効く AI 機能（多くは Studio 限定）

| 機能 | 何ができるか | 効率への効き方 |
| --- | --- | --- |
| **音声文字起こし / テキストベース編集** | 音声を文字起こしし、文字を消すと映像も消える | トーク・インタビュー・セミナー動画の粗編集が別次元で速くなる。**最優先で案内すべき機能** |
| **AI IntelliScript** | 台本テキストから、対応する箇所を並べたタイムラインを自動生成（Resolve 20 で追加） | 台本ありの収録なら粗編集を自動化できる |
| **Magic Mask** | 人物・物体を自動で切り抜き追跡 | ロトスコープ作業の削減。21 で Render in Place 追加 |
| **Voice Isolation** | 環境ノイズを除去して声を分離 | 録り直しの回避 |
| **Smart Reframe** | 16:9 → 9:16 などへ被写体追従でリフレーム | 縦動画への横展開が一気に片付く |
| **AI Multicam SmartSwitch** | 話している人を検出してアングルを自動切替 | 対談・複数人収録の切り替え作業を削減 |
| **Super Scale** | AI アップスケール | 低解像度素材の救済 |
| **Audio Classification / Dialogue Separator** | 音声の自動分類・分離 | Fairlight 側の整音を短縮 |

> **無料版か Studio かで回答が変わる。** これらの多くは Studio 限定。
> 「この機能が見当たらない」という質問には、まずバージョンと無料/Studio を確認する。

## コーチング／セミナー動画（このユーザーの想定用途）への当てはめ

1. **文字起こしベース編集**で「えー」「あのー」や言い直しを一気に削る（Studio）
2. 削ったあとの間（ま）を **ダイナミックトリム**で整える
3. 寄り／引きの変化は Cut ページの **Close Up** で機械的に付ける
4. テロップは **Text+ プリセット＋パワービン**で毎回同じスタイルを再利用
5. 音は **Normalize Audio Levels** でラウドネスを揃える（-14 LUFS 前後が配信向けの目安）
6. 書き出しは **レンダープリセット**を納品先ごとに保存して使い回す
