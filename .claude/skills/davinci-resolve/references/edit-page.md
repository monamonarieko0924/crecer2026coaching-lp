# Edit ページ ― 仕上げと素材管理の効率化

## 1. トラック運用でミスを減らす

- **Auto Select（自動選択）**: トラックヘッドの丸いアイコン。リップル削除・全体トリム・コピペの対象がここで決まる。
  「リップル削除したのに詰まらない」「削除したら別トラックまで消えた」の原因はほぼこれ。
- **ロック（鍵アイコン）**: 完成した BGM トラックやテロップトラックは編集中ロックしておく。事故が激減する。
- **リンク選択（Linked Selection）**: 映像と音声を一体で動かすかの切替。一時的に切り離したいときは `Alt`（Mac: `⌥`）を押しながらクリックすると片方だけ選択できる。
- **トラックの高さ**: 波形を見たいトラックだけ高くする。トラックヘッドを右クリックまたはドラッグ。

## 2. トリムの速い順

1. **キーボードトリム**: トリムモード `T` → 編集点をクリック → `,` `.`（1F）／`Shift+,` `Shift+.`（5F）
2. **ダイナミックトリム**: 再生しながら J/K/L でトリム。会話の間（ま）を詰める作業に強い
3. **数値入力トリム**: 編集点を選択して数値を打ち込む（例: `-10` で10フレーム詰める）
4. マウスドラッグ ← 一番遅い。精度も出ない

**リップル / ロール / スリップ / スライドの違い**（聞かれたときの説明用）
- リップル: 片側を伸縮し、以降のクリップが前後にずれる（全体尺が変わる）
- ロール: 隣接2クリップの境目だけ動かす（全体尺は変わらない）
- スリップ: クリップの位置・尺はそのまま、中身（使う範囲）だけずらす
- スライド: クリップの中身はそのまま、置かれる位置だけずらす（前後クリップが伸縮）

## 3. 素材を探す時間をゼロに近づける

- **スマートビン（Smart Bin）**: 条件（キーワード、解像度、フレームレート、フラグ、日付など）に合う素材が自動で集まる仮想ビン。
  素材を手で仕分けるのをやめて、**取り込み時にメタデータ／キーワードを入れる**運用に切り替えるのが本筋。
- **パワービン（Power Bin）**: **プロジェクトをまたいで共有される**ビン。
  ロゴ、オープニング、定番テロップ（Text+）、効果音、BGM、透かし、テンプレートはここに入れる。
  メディアプールの `…` メニュー → `Show Power Bins` で表示。
  → 継続的にシリーズ物を作るなら、これを整備するのが最大の時短。
- **メタデータビュー**: Media ページでシーン／ショット／キーワード／コメントを一括入力。
- **フラグとマーカー**: フラグはクリップ単位、マーカーは時間位置単位。
  マーカーは色分けして「要修正=赤」「テロップ入れる=青」のように運用すると、後工程でマーカーリストから飛べる。

## 4. 同じ作業を繰り返さない仕組み

- **Paste Attributes（`Alt+V` / `⌥V`）**: 変形・クロップ・合成・スピード・カラー・エフェクトを選んで一括適用。
- **調整クリップ（Adjustment Clip）**: エフェクトライブラリ内。上のトラックに置くと、その下の全クリップにエフェクトがかかる。
  ルック統一、ビネット、フィルムグレイン、全体のシャープなどはこれ一択。
- **コンパウンドクリップ（Compound Clip）**: 複数クリップを1つにまとめる。まとめてリタイム・まとめてエフェクトが可能。
  ただし後から中身を触る予定があるなら乱用しない。
- **タイムラインテンプレート化**: オープニング・エンディング・定型テロップを組んだタイムラインを作り、パワービンに置いて毎回複製する。
- **Text+ のプリセット保存**: インスペクタ上部のプリセット欄からスタイルを保存。フォント・縁取り・影・位置をまとめて再利用できる。
- **Fusion マクロ**: 作り込んだテロップやアニメーションはマクロ化してエフェクトライブラリに登録。
- **レンダープリセット**: Deliver ページで書き出し設定を保存。納品先ごとに1つずつ作っておく。

## 5. タイムライン運用の細かい時短

- タイムラインは**複製して世代管理**する（右クリック → Duplicate Timeline）。`_v01`, `_v02` と名前を付ける。取り消し履歴に頼らない。
- **タイムライン間コピー**: 別タイムラインのクリップをコピー → 貼り付け先で `Ctrl+V`。トラック構成が違うと位置がずれるので Auto Select を確認。
- **ギャップの一括削除**: タイムラインを右クリック → ギャップ選択、または編集メニューから。
- **クリップの有効／無効**: `D` でクリップを一時的に無効化（削除せず比較できる）⚠️要確認。
- **タイムラインの検索**: 素材数が多いときはメディアプール検索とタイムラインのクリップ名表示を併用。

## 6. 音まわり（編集速度に直結する）

- **音声の自動同期**: Media ページで複数クリップ選択 → 右クリック → `Auto Sync Audio`（波形 / タイムコード）。
- **Fairlight に行かずに済ませる**: 単純なレベル調整はクリップの音量ライン（クリップ中央の水平線）をドラッグ、または `Ctrl+Alt+↑/↓` ⚠️要確認。
- **ノーマライズ**: 音声クリップを複数選択 → 右クリック → `Normalize Audio Levels`。ラウドネス（-14 LUFS など）指定でまとめて揃う。ナレーション主体の動画で毎回効く。
- **Voice Isolation（Studio）**: 環境ノイズを除去してしゃべりを持ち上げる。Fairlight のクリップインスペクタから。
