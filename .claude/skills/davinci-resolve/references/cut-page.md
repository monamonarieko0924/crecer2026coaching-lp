# Cut ページ ― 速度特化ページの使いどころ

Cut ページは「素材を投げ込んで最短で粗編集を終わらせる」ために設計されたページ。
Edit ページの簡易版ではなく、**別の思想のページ**。長尺（インタビュー、セミナー、対談、ウェビナー、講座動画）で効果が大きい。

## Cut ページ vs Edit ページ 使い分け

| | Cut ページ | Edit ページ |
| --- | --- | --- |
| 得意 | 粗編集、素材の一気見、テンポよく詰める、マルチカムの抜き差し | 精密トリム、レイヤー構成、エフェクト、テロップ設計、複雑なトラック管理 |
| タイムライン | 上段=全体、下段=拡大の**デュアルタイムライン**（スクロール不要） | 単一タイムライン＋ズーム操作 |
| トラック | 少数トラック前提でシンプル | 多層トラック前提 |
| 向いている尺 | 長尺素材から抜き出す作業 | 完成形へ仕上げる作業 |

**推奨フロー**: Cut ページで粗編集 → Edit ページで仕上げ。同じプロジェクト・同じタイムラインを行き来できる（`Shift+2` / `Shift+3`）。

## デュアルタイムライン

Cut ページのタイムラインは上下2段。
- **上段**: タイムライン全体を常に俯瞰（ズーム／スクロール不要）
- **下段**: 再生ヘッド周辺の拡大表示（フレーム単位の作業用）

「タイムラインを拡大縮小してスクロールする」という往復動作が丸ごと消えるのが最大の時短ポイント。

## ソーステープ（Source Tape）

ビン内の全クリップを **1本の連続したテープのように** ビューアで再生できる機能。

- ビンを選択 → 画面左上の **Source Tape** ボタンをクリック
- クリップを1つずつ開いて閉じる、という動作が不要になる
- 頭から流しながら `I` / `O` で使う範囲をマークし、そのままタイムラインへ送る

**B ロール選び・ストック素材選び・大量のテイクからの選別**で圧倒的に速い。

## Fast Review

再生ボタンの近くにある Fast Review を使うと、**クリップの長さに応じて自動で再生速度を変えながら**素材を一気に流し見できる（長いクリップは速く、短いクリップはゆっくり）。
撮影素材のあたりを付ける最初の1周に使う。

## シンクビン（Sync Bin）とソース上書き（Source Overwrite）

マルチカメラ収録の切り替えを、従来のマルチカム機能より速くやるための仕組み。

1. タイムラインにメインカメラ（またはガイド音声）を並べる
2. **Sync Bin** を開くと、再生ヘッドの時刻に同期している全カメラのクリップがマルチビューで表示される
3. タイムラインをスクロールすると、その瞬間の各カメラ映像が一覧で見える
4. 使いたいアングルをクリックし、`I` / `O` で範囲を決める
5. **Source Overwrite** で挿入すると、**下のクリップとフレーム同期した状態で**上のトラックに乗る

同期は事前に取っておく必要がある。音声同期は Media ページで対象クリップを複数選択 → 右クリック → **Auto Sync Audio**（波形／タイムコード）。

## ライブ上書き（Live Overwrite）

再生しながらアングルを「塗る」ように差し込むモード。Speed Editor（専用ハードウェア）のカメラボタン＋サーチダイヤルと組み合わせると本領を発揮する。

## Cut ページのその他の時短機能

- **Smart Insert**: 再生ヘッドに最も近い編集点へスナップして挿入する。フレーム位置を目で合わせる作業が消える。
- **Close Up**: 選択クリップに自動で寄りのフレーミング（拡大）を当てる。1カメのトーク動画で「たまに寄る」演出を一瞬で作れる。
- **Boring Detector**: 「長すぎるショット」「短すぎるショット」をタイムライン上に赤帯で警告してくれる。テンポ調整のセルフチェックに使う。
- **Detect Scene Cuts**: すでに書き出された1本の動画を、シーンの切り替わりで自動分割する（Media ページのシーンカット検出）。再編集や素材の作り直しに有効。
- **Sync Bin / Source Tape はビン単位で動く**ため、**先にビン整理をしておくほど速くなる**。

## Speed Editor（ハードウェア）

Cut ページの機能をフルに引き出す専用キーボード。サーチダイヤル＋専用キー（CAM 1〜9、SOURCE、SMART INSERT、TRIM IN/OUT など）で、マウスをほぼ触らずに粗編集できる。
長尺・多カメラを日常的に扱うなら投資対効果が高い。Edit / Color ページでも一部機能が使える。
