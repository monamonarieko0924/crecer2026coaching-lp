# ショートカット（DaVinci Resolve デフォルトキーボードレイアウト）

凡例:
- ✅ = 複数の情報源で一致、かつ長年バージョン間で変わっていない定番
- ⚠️要確認 = バージョン／プリセット／OS で差がある可能性あり。断定せず `Keyboard Customization` での確認を案内すること

## 0. まずここ：キーボードカスタマイズ

`DaVinci Resolve`（Mac）/ `Help`〜環境設定（Win）→ **Keyboard Customization**

- 右上のプリセット切替で **DaVinci Resolve / Premiere Pro / Final Cut Pro 7 / Avid Media Composer** などに変更可能。
  Premiere から移行してきた人はここを変えるだけで初速が劇的に上がる。
- 検索ボックスで機能名（例: `Ripple Delete`）を引けば、そのバージョンでの正解キーが即分かる。
- 独自プリセットは保存・書き出しできるので、環境を移すときに持ち運べる。

## 1. 再生・移動（最重要）

| 操作 | キー | 状態 |
| --- | --- | --- |
| 再生 / 停止 | `Space` | ✅ |
| 逆再生 / 停止 / 再生 | `J` / `K` / `L` | ✅ |
| 早送り・早戻し（押すたび加速） | `J` 連打 / `L` 連打 | ✅ |
| 1フレーム戻る / 進む | `K`+`J` / `K`+`L`（押しながら） | ✅ |
| スロー再生 | `K`+`L` 長押し | ⚠️要確認（おおむね1/2速） |
| 1フレーム戻る / 進む | `←` / `→` | ✅ |
| 1秒戻る / 進む | `Shift+←` / `Shift+→` | ✅ |
| 前 / 次の編集点へ | `↑` / `↓` | ✅ |
| タイムラインの先頭 / 末尾 | `Home` / `End` | ✅ |
| シネマビューア（全画面プレビュー） | `P` | ⚠️要確認 |

> **効率のコツ**: J/K/L は左手のホームポジションから動かさずに押せる。カット編集中は右手をマウスに置いたまま左手だけで頭出しできる状態を作るのが理想。

## 2. イン点・アウト点

| 操作 | キー | 状態 |
| --- | --- | --- |
| イン点 / アウト点をマーク | `I` / `O` | ✅ |
| イン点 / アウト点をクリア | `Alt+I` / `Alt+O`（Mac: `⌥I` / `⌥O`） | ⚠️要確認 |
| イン・アウト両方クリア | `Alt+X`（Mac: `⌥X`） | ⚠️要確認 |
| クリップ全体をマーク | `X` | ✅ |
| イン点 / アウト点へ移動 | `Shift+I` / `Shift+O` | ⚠️要確認 |

## 3. 編集（Edit ページのデフォルト）

| 操作 | キー | 状態 |
| --- | --- | --- |
| インサート編集 | `F9` | ✅ |
| 上書き（オーバーライト）編集 | `F10` | ✅ |
| 置き換え（リプレース）編集 | `F11` | ✅ |
| 最上位トラックに配置（Place on Top） | `F12` | ✅ |
| リップル上書き（Ripple Overwrite） | `Shift+F10` | ✅ |
| フィット・トゥ・フィル（Fit to Fill） | `Shift+F11` | ✅ |
| 末尾に追加（Append at End） | `Shift+F12` | ✅ |

> Mac では OS 側のファンクションキー設定（Fn キー併用）に注意。`システム設定 → キーボード → ファンクションキーを標準のF1〜F12として使用` を ON にしておくと事故が減る。

> **Cut ページのツールバーボタン**（Smart Insert / Append / Ripple Overwrite / Close Up / Place on Top / Source Overwrite）は Edit ページの F9〜F12 とは対応関係が異なる場合がある。
> ⚠️要確認：Cut ページの割り当てを聞かれたら、`Keyboard Customization` で `Smart Insert` などを検索して確認するよう案内すること。Speed Editor には専用の物理キーがある。

## 4. カット・削除

| 操作 | キー | 状態 |
| --- | --- | --- |
| ブレード（カット）ツールに切替 | `B` | ✅ |
| 選択（矢印）ツールに切替 | `A` | ✅ |
| トリム編集モード | `T` | ✅ |
| ダイナミックトリムモード | `W` | ⚠️要確認 |
| 再生ヘッド位置でクリップを分割（Split Clip） | Win: `Ctrl+\` / Mac: `⌘\` | ⚠️要確認（`Ctrl+B` 系の割り当ての環境もある） |
| クリップを結合（Join Clips） | Win: `Alt+\` / Mac: `⌥\` | ⚠️要確認 |
| 削除（ギャップを残す＝リフト） | `Backspace` | ⚠️要確認 |
| リップル削除（ギャップを詰める） | Win: `Shift+Backspace` / Mac: `Shift+Delete`（または前方 Delete） | ⚠️要確認 |

> **これは特に環境差が出る箇所。** 「削除するとギャップが残る／残らない」の質問が来たら、まず
> `Keyboard Customization` で `Ripple Delete` を検索して現在の割り当てを見てもらうのが最短。
> なお、リップル削除が効かない典型原因は **トラックの Auto Select（自動選択）が OFF** になっていること。

## 5. トリム（マウスを使わない）

| 操作 | キー | 状態 |
| --- | --- | --- |
| 選択中の編集点／クリップを1フレーム左右へ | `,` / `.` | ✅ |
| 同・5フレーム（複数フレーム）単位 | `Shift+,` / `Shift+.` | ✅ |
| 再生ヘッドまでリップルトリム（開始点／終了点） | ⚠️要確認 | — |

> トリムモード（`T`）に入ってから編集点をクリックし、`,` `.` で追い込むのが一番速い。
> ダイナミックトリムは再生しながら J/K/L でトリム量を決められる。長尺のトークもので有効。

## 6. タイムライン表示

| 操作 | キー | 状態 |
| --- | --- | --- |
| タイムライン全体を表示（ズームフィット） | `Shift+Z` | ✅ |
| ズームイン / アウト | Win: `Ctrl+=` / `Ctrl+-`、Mac: `⌘=` / `⌘-` | ✅ |
| ズーム（ポインタ基準） | `Alt`（Mac: `⌥`）+ マウスホイール | ✅ |
| スナップの ON/OFF | `N` | ✅ |
| マーカーを追加 | `M` | ✅ |
| マーカーを追加してすぐ編集 | `M` を2回 | ⚠️要確認 |
| フラグを追加 | `G` | ⚠️要確認 |

## 7. ページ切替

`Shift+1` メディア / `Shift+2` カット / `Shift+3` エディット / `Shift+4` Fusion / `Shift+5` カラー / `Shift+6` Fairlight / `Shift+7` デリバー ✅

> **注意**: Undo（`Ctrl+Z` / `⌘Z`）はページごとに独立したスタックを持つ。カラーページで戻したつもりが編集が戻る、という事故は起きない代わりに、「戻らない」ときはページを間違えている可能性を疑う。

## 8. その他よく使う

| 操作 | キー | 状態 |
| --- | --- | --- |
| コピー / ペースト | `Ctrl+C` / `Ctrl+V`（Mac: `⌘C` / `⌘V`） | ✅ |
| 属性をペースト（Paste Attributes） | `Alt+V`（Mac: `⌥V`） | ✅ |
| 取り消し / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` | ✅ |
| 保存 | `Ctrl+S` / `⌘S` | ✅ |
| リタイムコントロールを表示 | `Ctrl+R` / `⌘R` | ⚠️要確認 |
| フリーズフレーム | `Shift+R` | ⚠️要確認 |

> **Paste Attributes は効率化の要**。1つのクリップで作った拡大・位置・カラー・エフェクト設定を、複数クリップにまとめて適用できる。
> 「同じ処理を何十クリップにも当てたい」という質問には、まず Paste Attributes か **調整クリップ（Adjustment Clip）** を提案する。
