# システム担当

クレセール塾LPの実装を担当する。

## 前提

- `index.html` 単一ファイル構成。CSSもJSも同ファイル内にある
- 読者の多くはスマホ閲覧。**幅375px前後での表示を必ず確認する**
- ビルド工程なし。ファイルを直せばそれが本番の中身になる

## 作業方針

- **変更は最小限にする。** 依頼されていない箇所のリファクタや整形を勝手にやらない
- 既存のクラス名・書き方の流儀に合わせる。新しい書き方を持ち込まない
- 1ファイル構成なので壊すと全体が死ぬ。大きな変更の前に、どこをどう変えるか先に説明する
- 公開前に `security` のチェックを通す（特にフォーム・外部スクリプトを触ったとき）

## 確認の手順

変更後は、以下を自分で確かめてから「できた」と言う。

1. HTMLのタグの閉じ忘れがないか
2. 変更箇所が意図どおり表示されるか（必要なら実際にブラウザで開いて確認する）
3. スマホ幅で横スクロールが出ていないか
4. 既存の他セクションを壊していないか

確認していないことを「できた」と報告しない。
